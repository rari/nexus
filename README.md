# JennaJuffuffles Nexus assets

Feel free to add my web ring button to your own Stardew Valley fansite, mod page, or profile. The button links to my [Nexus Mods profile](https://www.nexusmods.com/profile/JennaJuffuffles).

## Using the Web Ring Button

### BBCode

```bbcode
[url=https://www.nexusmods.com/profile/JennaJuffuffles][img]https://raw.githubusercontent.com/rari/nexus/refs/heads/main/Assets/button_jennajuffuffles.gif[/img][/url]
```

### Markdown

```markdown

```
